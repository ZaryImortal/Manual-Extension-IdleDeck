# Manual-Extension-IdleDeck
Add your own extensions to your IdleDeck accounts.

The files were created based on adding extensions for the idle game [pokeidle.io](https://pokeidle.io/?ref=WMZQJQ7), but you can edit them for any game you like, simply edit this part of the code `s.url.includes('pokeidle')` with your game's URL name, example: for the game poke.idleworld.com `s.url.includes('idleworld')` .
It will add the extension to all game accounts specified in the file (by default, [pokeidle.io](https://pokeidle.io/?ref=WMZQJQ7)); you can create multiple files—one for each game—and it will install the extension on all accounts for that game.
